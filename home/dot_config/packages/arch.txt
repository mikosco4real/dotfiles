# pacman packages for Arch and Arch-based distros (Manjaro, EndeavourOS, CachyOS).
# One package per line. Blank lines and # comments are ignored.
# Consumed by .chezmoiscripts/run_onchange_before_11-packages-linux.sh.tmpl
#
# Scope note. Unlike debian.txt this list is LONG, and deliberately so: on Arch
# there is no Homebrew at all. The two reasons Debian needs a brew top-up do not
# apply here —
#
#   1. Versions. Arch ships current releases. Neovim in `extra` is 0.12+, which
#      is what this config requires for vim.pack; Ubuntu 24.04 is still on 0.9.x.
#   2. Naming. Arch does not rename binaries. `bat` is bat and `fd` is fd, so the
#      aliases and configs need no per-distro special cases.
#
# So pacman owns everything that Homebrew owns on macOS and Debian. The handful
# of tools with no official-repo package live in arch-aur.txt instead.
#
# Keep this in step with the cross-platform section of dot_config/homebrew/Brewfile.
